# Security Policy

## Reporting a Vulnerability

We take security seriously. Please report security vulnerabilities by emailing the maintainers directly.

**Do not** create public GitHub issues for security vulnerabilities.

### What to include:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

## Disclosure Policy

- We will acknowledge receipt within 48 hours
- We will provide a timeline for fix and disclosure
- We will notify reporters when the fix is deployed

## Supported Versions

| Version | Supported |
|---------|-----------|
| latest  | Yes       |
| < latest| No        |
